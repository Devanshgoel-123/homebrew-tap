# Homebrew tap for DiskPilot

```sh
brew tap devanshgoel-123/tap
brew trust devanshgoel-123/tap
brew install --cask diskpilot
```

Update with `brew upgrade --cask diskpilot`.

DiskPilot is a free, open-source Mac app that explains what is filling your disk and what is safe to clear. Source: https://github.com/Devanshgoel-123/diskpilot
